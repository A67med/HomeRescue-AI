HOME RESCUE AI - تجهيز تسليم تقييم الدكتور
========================================
المرحلة الحالية: مشروع صاحبك وكود SQL موجودين؛ قاعدة بيانات homerescue_dw اتعملت على جهازك لكنها لم تحمل بيانات بعد.

✅ موجود وجاهز داخل الملف:
- رابط كل مصدر + Source Audit + Idea Question
- Bronze / Silver / Gold SQL scripts
- ملف Demo SQL لعرض قواعد البيانات والجداول والنتائج قدام الدكتور
- Buildings.csv (22,404) وOMO.csv (490) من ملفك الرسمي الكبير
- برنامج تحميل تلقائي للمصدرين اللي ملفاتهما اتقطعت أثناء التحميل (Complaints / Violations)
- مولّد 3 تقارير PDF من القاعدة الحقيقية بعد التنفيذ
- خطوة Backup .bak بعد نجاح التنفيذ

⚠ لماذا ليس ملف القاعدة جاهز بالفعل؟
القاعدة موجودة على جهازك localhost، ومن هنا لا يمكن الاتصال بها. لا يوجد .bak داخل الملف المرفوع.
ملف ZIP الكبير كان فيه Error 500 داخل CSV الشكاوى والمخالفات، لذلك لا يجوز استخدامها كأنها مكتملة.

تشغيل المشروع على جهازك:
1. فك ضغط هذا ZIP بالكامل في فولدر عادي (مثلا Desktop\HomeRescue_AI_Evaluation).
2. تأكد أن SQL Server 2025 + SSMS شغالان (أنت بالفعل ثبّتّهما).
3. دبل كليك على 01_RUN_PROJECT.bat.
4. لو Python غير موجود، هتفتح صفحة تحميل Python؛ ثبّت Python 3.12 وفعّل Add Python to PATH ثم شغّل الباتش تاني.
5. الملف هيحمّل البيانات الناقصة من الإنترنت ويتأكد منها ثم يعمل Bronze وSilver وGold ويشغّل الاختبارات ويكتب PDF جديد لكل طبقة.
6. لازم تشوف كلمة SUCCESS وRUN_STATUS.txt = PASS.
7. افتح 06_Demo\DEMO_QUERIES.sql في SSMS عشان توري الدكتور النتائج الحقيقية.

لو شفت ERROR: افتح RUN_LOG.txt، لأن معناها التقييم لسه مش جاهز. لا تعرض أرقام التقارير القديمة على أنها نتائج جديدة.

ملفات المطلوب حسب ترتيب الدكتور:
01_Sources_and_Datasets/  المصادر والـ CSV (تكمل بعد التشغيل)
02_Idea_Question/         سؤال المشروع
03_Bronze/                00_init.sql + 01_bronze.sql + BRONZE_REPORT.pdf بعد التشغيل
04_Silver/                02_silver.sql + SILVER_REPORT.pdf بعد التشغيل
05_Gold/                  03_gold.sql .. 06_analytics.sql + GOLD_REPORT.pdf بعد التشغيل
06_Demo/                  استعلامات جاهزة للعرض + شرح عربي
07_Database_Backup/       Backup .bak بعد نجاح التشغيل (حسب صلاحيات ويندوز)

مهم: Bronze / Silver / Gold عبارة عن Schemas في نفس SQL Server Database واسمه homerescue_dw.

ملحوظة: ملفات PDF القديمة والأرقام التاريخية محفوظة للرجوع فقط في docs\PREVIOUS_RUN_REFERENCE.

8. بعد نجاح التشغيل اضغط 02_OPEN_FOR_EVALUATION.bat لفتح ملفات العرض المطلوبة.
